## Purpose

Find the minimum flexure thickness this printer can produce consistently. Print it, measure every strip with calipers, then bend each one by hand. The thinnest strip that prints completely, measures close to nominal and survives handling sets `min_flexure_thickness_mm` in the printer config. Until that number is measured, every feasibility verdict the toolkit produces is flagged as not a physical prediction.

## Slicer settings (OrcaSlicer)

Design choices for printing thin flexures consistently, not measurements.
Verify the exact setting names in your slicer version.

| Setting | Value | Why |
| --- | --- | --- |
| wall_generator | `Arachne` | The single most important setting. Arachne varies extrusion width to fill thin features exactly. The classic generator works in whole-nozzle-width perimeters and will thin, distort or silently drop a sub-2-perimeter wall -- which is every flexure in this project. In OrcaSlicer this is under Quality > Precision > Wall generator. |
| wall_loops | `4` | Enough perimeters that rigid links are solid; flexures are thinner than this and become a single variable-width wall. |
| sparse_infill_density_percent | `100` | Rigid links must be rigid, and density must be uniform for a modulus measured on a coupon to apply to a mechanism. Sparse infill makes 'rigid' links compliant and adds a second unmeasured variable. |
| sparse_infill_pattern | `rectilinear` | At 100 percent the pattern barely matters, but rectilinear is predictable and fast. |
| detect_thin_wall | `True` | Prevents narrow regions being skipped entirely. |
| first_layer_height_mm | `0.2` | Same as the rest. A thicker first layer would make the bottom layer of a 0.6 mm flexure a different width from the layers above it, which is a geometry error in the dimension that matters most. |
| first_layer_flow_ratio | `1.0` | Leave nominal. The usual habit of over-extruding the first layer for adhesion widens the bottom of every flexure. Use a brim for adhesion instead. |
| flow_ratio | _to be set_ | PLACEHOLDER: calibrate on this machine before the first `print_purpose: data` part. Flow error goes straight into flexure thickness, which enters stiffness as t^3 -- a 5 percent flow error is a 16 percent stiffness error. Calibrate with a flow test, then record the value here with status: measured. |
| brim_type | `outer_only` | The strain-test strips are tall free-standing walls and will topple without a brim. |
| seam_position | `aligned, placed away from flexures` | A layer seam on a flexure is a stress concentrator and a crack initiation site. |
| outer_wall_speed_mm_per_s | `25` | Slower than the A1 setting: the Kobra is a bed-slinger, so inertia on a tall thin wall is worse. Reduce further if 0.4-0.5 mm strips come out inconsistent. |
| supports | `False` | Parts are designed flat with the mechanism plane on the bed; support material on a flexure would ruin its surface. |
| nozzle_temperature_c | _to be set_ | PLACEHOLDER: use the filament vendor's figure for the actual spool and log it. |
| bed_temperature_c | _to be set_ | PLACEHOLDER: as above. |

## How to run this test

1. Print flat on the bed with the settings in the table above. No supports.
2. Photograph the plate before touching it, and note any strip that failed to print.
3. Measure each strip's thickness with calipers at three points along its length.
4. Record nominal against measured thickness, and the spread across those points.
5. Bend each paddle by hand through roughly 20 degrees and back, ten times.
6. Record which strips survive, which whiten, and which break.
7. Set `min_flexure_thickness_mm` in configs/printer/bambu_a1.yaml from the result, with `status: measured` and the date.
